## 📌 Overview

**Help Desk** is a full-stack ticket management application designed to model a basic IT support / customer support workflow.

Users can:

- 👤 Create an account
- 🔐 Log in
- 🎫 Create support tickets
- 🚨 Assign ticket priority
- 🏢 Select a department
- 📎 Upload attachments
- 📋 View previously created tickets
- 🔎 View individual ticket details
- 🌗 Toggle the dashboard theme

Administrators can:

- 📊 View all submitted tickets
- 📈 Visualize tickets by priority
- 🔎 Open individual ticket details
- 🗑️ Delete selected tickets
- 🚪 Log out from the admin dashboard

# ✨ Features

## 👤 User Features

| Feature | Description |
|---|---|
| 📝 Registration | Create a new user account |
| 🔐 Login | Authenticate using username and password |
| 🎫 Create Ticket | Submit a new support request |
| 🚨 Priority | Low, Mid, High, Emergency |
| 🏢 Department | Product, Sales, Support |
| 📎 Attachments | Upload files with tickets |
| 📋 Ticket History | View tickets associated with a user |
| 🔍 Ticket Details | View complete ticket information |
| 🌗 Theme | Toggle dashboard appearance |
| 🚪 Logout | Clear local session information |

## 🛡️ Admin Features

| Feature | Description |
|---|---|
| 📊 Admin Dashboard | Centralized ticket management |
| 📋 All Tickets | View all submitted tickets |
| 📈 Priority Chart | Visualize ticket distribution |
| 🔍 Ticket Details | Inspect individual tickets |
| ☑️ Selection | Select multiple tickets |
| 🗑️ Delete | Delete selected tickets |
| 🚪 Logout | End the local session |
